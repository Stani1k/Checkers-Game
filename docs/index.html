Get started

Requires the .NET 10 SDK. The WPF app needs Windows.

git clone https://github.com/Stani1k/Checkers-Game.git
cd Checkers-Game
dotnet build Checkers-Game.sln

# Console app
dotnet run --project Checkers.Console

# WPF app (Windows)
dotnet run --project Checkers.WPF

Rules in a minute

  1. Move diagonally forward one square onto an empty dark square.
  2. Capture by jumping over an adjacent opponent piece into the empty square behind it.
  3. Captures are mandatory — if you can jump, you must.
  4. Reach the far side to crown a king, which can move backward too.
  5. Win by capturing or blocking all of the opponent's pieces.
